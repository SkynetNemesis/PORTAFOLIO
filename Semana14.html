Semana 14: Desarrollo Backend con Python Flask

Introducción a Flask

Flask es un microframework web ligero para Python que permite crear aplicaciones web rápidamente con un mínimo de código.

Características principales

  • Microframework minimalista
  • Sistema de routing simple
  • Integración con Jinja2 para templates
  • Extensible con extensiones
  • Servidor de desarrollo integrado
  • Compatibilidad con WSGI

Instalación básica

pip install flask

Aplicación Flask mínima

# app.py
from flask import Flask

app = Flask(__name__)

@app.route('/')
def home():
  return '¡Hola Mundo con Flask!'

if __name__ == '__main__':
  app.run(debug=True)

Routing y Vistas

Flask usa decoradores para definir rutas y las funciones asociadas que manejan las peticiones.

Ejemplos de routing

@app.route('/about')
def about():
  return 'Acerca de nosotros'

@app.route('/user/<username>')
def show_user(username):
  return f'Usuario: {username}'

@app.route('/post/<int:post_id>')
def show_post(post_id):
  return f'Post #{post_id}'

Métodos HTTP

@app.route('/login', methods=['GET', 'POST'])
def login():
  if request.method == 'POST':
    return 'Procesar login'
  else:
    return 'Mostrar formulario login'

Templates con Jinja2

Flask integra Jinja2 como motor de plantillas para generar HTML dinámico.

Estructura básica

# app.py
from flask import render_template

@app.route('/hello/<name>')
def hello(name):
  return render_template('hello.html', name=name)

Ejemplo de template (hello.html)

<!-- templates/hello.html -->
<!DOCTYPE html>
<html>
<head>
  <title>Saludo</title>
</head>
<body>
  <h1>Hola {{ name }}!</h1>
  {% if name == 'admin' %}
    <p>Eres un usuario especial</p>
  {% else %}
    <p>Bienvenido a nuestro sitio</p>
  {% endif %}
</body>
</html>

Trabajando con Bases de Datos

Flask no incluye un ORM nativo, pero se integra bien con SQLAlchemy.

Configuración de Flask-SQLAlchemy

from flask_sqlalchemy import SQLAlchemy

app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///database.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

db = SQLAlchemy(app)

class User(db.Model):
  id = db.Column(db.Integer, primary_key=True)
  username = db.Column(db.String(80), unique=True, nullable=False)
  email = db.Column(db.String(120), unique=True, nullable=False)

  def __repr__(self):
    return f'<User {self.username}>'

Operaciones básicas

# Crear tablas
db.create_all()

# Crear usuario
new_user = User(username='juan', email='juan@example.com')
db.session.add(new_user)
db.session.commit()

# Consultar usuarios
users = User.query.all()
admin = User.query.filter_by(username='admin').first()

Formularios y Validación

Flask-WTF simplifica el manejo de formularios web con validación integrada.

Definición de formulario

from flask_wtf import FlaskForm
from wtforms import StringField, PasswordField
from wtforms.validators import DataRequired, Email

class LoginForm(FlaskForm):
  email = StringField('Email', validators=[DataRequired(), Email()])
  password = PasswordField('Password', validators=[DataRequired()])

Manejo del formulario en la vista

@app.route('/login', methods=['GET', 'POST'])
def login():
  form = LoginForm()
  if form.validate_on_submit():
    # Procesar datos del formulario
    return 'Login exitoso'
  return render_template('login.html', form=form)

Template del formulario

<!-- templates/login.html -->
<form method="POST">
  {{ form.hidden_tag() }}
  <div>
    {{ form.email.label }}
    {{ form.email() }}
    {% for error in form.email.errors %}
      <span style="color: red;">{{ error }}</span>
    {% endfor %}
  </div>
  <div>
    {{ form.password.label }}
    {{ form.password() }}
  </div>
  <button type="submit">Login</button>
</form>
