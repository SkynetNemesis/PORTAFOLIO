Semana 3: Fundamentos de CSS - Estilos, Selectores y Flexbox

¿Qué es CSS?

CSS (Cascading Style Sheets) es un lenguaje de diseño gráfico para definir y crear la presentación de un documento estructurado escrito en HTML.

Permite controlar el aspecto visual de las páginas web, incluyendo colores, fuentes, espaciados, tamaños, posicionamiento y mucho más.

Características principales:

  • Separación de contenido y presentación: El HTML se encarga del contenido, el CSS del diseño
  • Hojas de estilo en cascada: Las reglas se aplican en cascada según su especificidad
  • Reutilización de código: Un mismo estilo puede aplicarse a múltiples elementos
  • Responsive design: Permite crear diseños adaptables a diferentes dispositivos
  • Animaciones y transiciones: Posibilita crear efectos visuales sin JavaScript

Ventajas de usar CSS:

  • Mayor control sobre el diseño
  • Sitios más rápidos al reducir el código HTML
  • Mantenimiento más sencillo
  • Consistencia visual en todo el sitio
  • Accesibilidad mejorada

Evolución Histórica de CSS

1994

Håkon Wium Lie propone por primera vez el concepto de CSS mientras trabajaba en el CERN junto con Tim Berners-Lee.

1996

Se publica CSS nivel 1 (CSS1) como recomendación oficial del W3C el 17 de diciembre.

1998

Lanzamiento de CSS nivel 2 (CSS2) con nuevas capacidades como posicionamiento absoluto y relativo.

1999-2000

Comienza el trabajo en CSS3, que se desarrolla como módulos independientes.

2011

Los primeros módulos de CSS3 (Selectores, Color, Media Queries) se convierten en recomendaciones oficiales.

2012-2016

Se estandarizan módulos importantes como Flexbox, Grid, Animaciones y Transiciones.

2020-actualidad

Nuevas características como CSS Variables, Subgrid, Container Queries y nuevas funciones de color.

Principales diferencias entre CSS2 y CSS3:

  • Módulos independientes: CSS3 se divide en módulos que evolucionan por separado
  • Nuevos selectores: Selectores de atributo, pseudo-clases avanzadas
  • Efectos visuales: Sombras, gradientes, bordes redondeados
  • Animaciones: Transiciones y animaciones nativas
  • Diseño flexible: Flexbox y Grid para layouts complejos
  • Responsive design: Media queries para adaptabilidad

Formas de Enlazar CSS

Método Sintaxis Ventajas Desventajas Uso recomendado
Inline (en línea) <p style="color: red;"> Especifidad máxima, rápido para pruebas Difícil mantenimiento, mezcla contenido/presentación Evitar, solo para casos muy específicos
Interno (embed) <style> p { color: red; } </style> Útil para estilos específicos de una página No reutilizable entre páginas Pequeños proyectos o estilos únicos
Externo (archivo .css) <link rel="stylesheet" href="estilos.css"> Mantenimiento fácil, reutilizable, caché del navegador Requiere HTTP request adicional Recomendado para la mayoría de casos
@import @import url("estilos.css"); Permite modularizar CSS Rendimiento inferior (carga secuencial) Uso dentro de archivos CSS para modularización

Ejemplo de enlace externo recomendado:

<!-- En el head del documento HTML -->
<link rel="stylesheet" href="css/estilos.css">

Jerarquía de aplicación (de mayor a menor prioridad):

  1. Estilos en línea (inline)
  2. Estilos internos (embed)
  3. Estilos externos
  4. Estilos del navegador (user agent)

Estructura CSS

/* Selector */
p, .clase, #id {
  propiedad: valor; /* Declaración */
  color: #333;
  margin: 1em 0;
  padding: 10px;
}

Componentes de una regla CSS:

  • Selector: Indica a qué elementos HTML se aplicará el estilo
  • Declaración: Conjunto de propiedades y valores entre llaves {}
  • Propiedad: Característica que se quiere modificar (color, tamaño, etc.)
  • Valor: Configuración específica para la propiedad

Tipos de valores comunes:

  • Colores: nombres (red), hexadecimal (#ff0000), rgb/rgba, hsl/hsla
  • Unidades de longitud: px, em, rem, %, vh, vw
  • Texto: fuentes, tamaños, estilos, decoraciones
  • Imágenes: url(), gradientes
  • Funciones: calc(), var(), attr()

Selectores CSS

Selectores básicos

  • p - Elementos <p>
  • .clase - class="clase"
  • #id - id="id"
  • * - Universal (todos)

Combinadores

  • div p - Descendientes
  • div > p - Hijos directos
  • div + p - Hermano adyacente
  • div ~ p - Hermanos generales

Atributos

  • [attr] - Con el atributo
  • [attr=valor] - Atributo exacto
  • [attr^=valor] - Comienza con
  • [attr$=valor] - Termina con

Pseudo-clases

  • :hover - Al pasar mouse
  • :nth-child(n) - Hijo número n
  • :not(selector) - Negación
  • :focus - En foco

Pseudo-elementos

  • ::before - Antes del contenido
  • ::after - Después del contenido
  • ::first-letter - Primera letra
  • ::selection - Texto seleccionado

Especificidad (de mayor a menor prioridad):

  1. !important - Rompe la cascada (evitar)
  2. Estilos en línea - style="..."
  3. IDs - #id
  4. Clases, atributos, pseudo-clases - .clase, [type="text"], :hover
  5. Elementos, pseudo-elementos - p, div, ::before

Flexbox

Flexbox es un modelo de layout unidimensional que permite distribuir el espacio entre los ítems de una interfaz y mejorar las capacidades de alineación.

Ideal para diseños que deben funcionar en diferentes tamaños de pantalla.

Conceptos clave:

  • Contenedor flex: Elemento con display: flex
  • Ítems flex: Hijos directos del contenedor
  • Eje principal: Dirección principal (row o column)
  • Eje transversal: Dirección perpendicular al principal

Propiedades del contenedor

  • display: flex | inline-flex
  • flex-direction: row | column | row-reverse | column-reverse
  • flex-wrap: nowrap | wrap | wrap-reverse
  • justify-content (alineación en eje principal)
  • align-items (alineación en eje transversal)
  • align-content (alineación de múltiples líneas)
  • gap, row-gap, column-gap (espacio entre ítems)

Propiedades de los ítems

  • order (controla el orden de aparición)
  • flex-grow (capacidad de crecimiento)
  • flex-shrink (capacidad de reducción)
  • flex-basis (tamaño base)
  • align-self (alineación individual)

Ejemplo: align-items

1
2

Ventajas de Flexbox:

  • Distribución inteligente del espacio disponible
  • Alineación poderosa en ambos ejes
  • Elementos pueden cambiar orden visual
  • Responsive sin media queries en muchos casos
  • Soporte en todos los navegadores modernos

Ejemplo completo:

.contenedor {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  gap: 20px;
}

.item {
  flex: 1 0 200px; /* grow | shrink | basis */
}
