Semana 13: Desarrollo Backend con Laravel

Introducción a Laravel

Laravel es un framework PHP elegante y expresivo para el desarrollo web. Sigue el patrón MVC y ofrece una sintaxis elegante que prioriza la experiencia del desarrollador.

Características principales

  • Sistema de enrutamiento expresivo
  • Motor de plantillas Blade
  • ORM Eloquent para bases de datos
  • Sistema de migraciones
  • Autenticación integrada
  • Ecosistema robusto (Forge, Vapor, Nova)

Instalación de Laravel

composer global require laravel/installer
laravel new mi-proyecto
cd mi-proyecto && php artisan serve

Arquitectura MVC en Laravel

Estructura de directorios clave

  • app/Http/Controllers - Controladores
  • app/Models - Modelos Eloquent
  • resources/views - Vistas Blade
  • routes/ - Definición de rutas
  • database/migrations - Migraciones

Ejemplo de Ruta + Controlador

// routes/web.php
Route::get('/productos', [ProductoController::class, 'index']);

// app/Http/Controllers/ProductoController.php
class ProductoController extends Controller {
  public function index() {
    return view('productos.index', [
      'productos' => Producto::all()
    ]);
  }
}

Eloquent ORM

Eloquent es el ORM (Mapeo Objeto-Relacional) incluido en Laravel, que proporciona una implementación simple y elegante para trabajar con bases de datos.

Modelo Eloquent básico

<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Producto extends Model {
  // Nombre de la tabla (opcional si sigue convenciones)
  protected $table = 'productos';

  // Campos asignables masivamente
  protected $fillable = ['nombre', 'precio', 'descripcion'];

  // Relación con categorías (ejemplo)
  public function categoria() {
    return $this->belongsTo(Categoria::class);
  }
}

Consultas comunes con Eloquent

// Obtener todos los productos
$productos = Producto::all();

// Buscar por ID
$producto = Producto::find(1);

// Consulta con condiciones
$productosCaros = Producto::where('precio', '>', 100)
                ->orderBy('nombre')
                ->get();

// Crear nuevo producto
$nuevoProducto = Producto::create([
  'nombre' => 'Nuevo Producto',
  'precio' => 99.99
]);

Vistas Blade

Blade es el motor de plantillas de Laravel que permite crear vistas dinámicas con una sintaxis limpia y expresiva.

Ejemplo de vista Blade

<!-- resources/views/productos/index.blade.php -->
@extends('layouts.app')

@section('content')
  <h1>Listado de Productos</h1>

  @if($productos->isEmpty())
    <p>No hay productos disponibles.</p>
  @else
    <ul>
      @foreach($productos as $producto)
        <li>{{ $producto->nombre }} - ${{ number_format($producto->precio, 2) }}</li>
      @endforeach
    </ul>
  @endif
@endsection

Directivas Blade comunes

Directiva Descripción
@if, @else, @endif Estructuras condicionales
@foreach, @endforeach Bucles sobre arrays/colecciones
@extends, @section Herencia de plantillas
@include Incluir sub-vistas
{{ }} Mostrar contenido escapado
{!! !!} Mostrar contenido sin escapar

Autenticación y Middleware

Autenticación en Laravel

Laravel incluye un sistema de autenticación completo que puede ser instalado con:

composer require laravel/ui
php artisan ui bootstrap --auth

Middleware de autenticación

// Proteger rutas
Route::get('/dashboard', function () {
  // Solo usuarios autenticados
})->middleware('auth');

// En controladores
public function __construct() {
  $this->middleware('auth')->only(['create', 'store']);
  $this->middleware('guest')->only(['login']);
}

Obtener usuario autenticado

// En controladores
$user = auth()->user();
$id = auth()->id();

// En vistas Blade
@auth
  Bienvenido {{ auth()->user()->name }}
@endauth
