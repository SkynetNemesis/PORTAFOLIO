Semana 5: Introducción a React - La biblioteca de JavaScript para interfaces de usuario

¿Qué es React?

React es una biblioteca de JavaScript desarrollada por Facebook para construir interfaces de usuario interactivas y componentes reutilizables.

Fue lanzada en 2013 y se ha convertido en una de las tecnologías más populares para el desarrollo frontend, utilizada por empresas como Facebook, Instagram, Netflix, Airbnb y muchas más.

Características principales:

Componentes

React organiza la UI en componentes independientes y reutilizables que manejan su propio estado.

JSX

Sintaxis similar a HTML que permite escribir estructura de componentes de manera declarativa.

Virtual DOM

React usa un DOM virtual para actualizar eficientemente solo las partes necesarias del DOM real.

Flujo de datos unidireccional

Los datos fluyen en una sola dirección (de padre a hijo), haciendo el código más predecible.

Hooks

API moderna que permite usar estado y otras características de React sin clases.

Ecosistema rico

Amplia comunidad y herramientas como React Router, Redux, Next.js, etc.

¿Por qué usar React?

  • Eficiencia: El Virtual DOM mejora el rendimiento de las aplicaciones
  • Reutilización: Los componentes pueden usarse múltiples veces
  • Mantenibilidad: Código más organizado y fácil de mantener
  • Popularidad: Gran comunidad y abundantes recursos de aprendizaje
  • Demanda laboral: Una de las habilidades más solicitadas en frontend

Principales Características de React

Componentes

Los componentes son los bloques de construcción de React. Pueden ser de dos tipos:

  • Componentes de clase: Usan sintaxis de clases ES6
  • Componentes funcionales: Usan funciones JavaScript
// Componente funcional
function Saludo(props) {
  return <h1>Hola, {props.nombre}</h1>;
}

// Componente de clase
class Saludo extends React.Component {
  render() {
    return <h1>Hola, {this.props.nombre}</h1>;
  }
}

JSX

JSX es una extensión de sintaxis que permite escribir HTML en JavaScript. No es obligatorio pero es muy usado.

// Ejemplo de JSX
const elemento = <h1 className="titulo">Hola Mundo!</h1>;

// Equivalente en JavaScript puro
const elemento = React.createElement(
  'h1',
  {className: 'titulo'},
  'Hola Mundo!'
);

Nota: JSX necesita ser compilado a JavaScript normal para que los navegadores lo entiendan.

Estado (State) y Props

Props

Son datos pasados de un componente padre a un componente hijo (inmutables).

// Uso de props
function Bienvenida(props) {
  return <h1>Hola, {props.nombre}</h1>;
}

// Llamada al componente
<Bienvenida nombre="Juan" />

Estado (State)

Datos internos de un componente que pueden cambiar (mutables).

// Estado con Hooks (versión moderna)
function Contador() {
  const [contador, setContador] = React.useState(0);

  return (
    <div>
      <p>Contador: {contador}</p>
      <button onClick={() => setContador(contador + 1)}>
        Incrementar
      </button>
    </div>
  );
}

Ciclo de Vida (Solo componentes de clase)

class Ejemplo extends React.Component {
  constructor(props) {
    super(props);
    this.state = { dato: '' };
  }

  componentDidMount() {
    // Se ejecuta después del primer render
    // Buen lugar para llamadas API
  }

  componentDidUpdate(prevProps, prevState) {
    // Se ejecuta después de cada actualización
  }

  componentWillUnmount() {
    // Se ejecuta antes de que el componente sea eliminado
    // Buen lugar para limpieza
  }

  render() {
    return <div>Ejemplo</div>;
  }
}

Hooks (Alternativa moderna al ciclo de vida)

import React, { useState, useEffect } from 'react';

function Ejemplo() {
  const [dato, setDato] = useState('');

  useEffect(() => {
    // Equivalente a componentDidMount y componentDidUpdate
    fetchData();

    return () => {
      // Equivalente a componentWillUnmount
      cleanUp();
    };
  }, []); // Array de dependencias

  return <div>Ejemplo</div>;
}

Herramientas de Instalación con React

Create React App (CRA)

La forma oficial y más sencilla de empezar un proyecto React. Configura automáticamente:

  • Bundler (Webpack)
  • Compilador (Babel)
  • Servidor de desarrollo
  • Configuración básica para testing
  • Optimizaciones para producción

1. Instalar Node.js

React requiere Node.js (que incluye npm) para funcionar. Descargar de nodejs.org.

Verificar instalación:

node --version
npm --version

2. Crear proyecto con Create React App

Ejecutar en terminal:

npx create-react-app mi-proyecto

O con yarn:

yarn create react-app mi-proyecto

3. Navegar al directorio del proyecto

cd mi-proyecto

4. Iniciar servidor de desarrollo

npm start

O con yarn:

yarn start

Esto abrirá automáticamente tu navegador en http://localhost:3000

5. Comandos útiles adicionales

Para construir versión de producción:

npm run build

Para ejecutar tests:

npm test

Para ejectuar (extraer configuración):

npm run eject
