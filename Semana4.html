Evolución de JavaScript

JavaScript es un lenguaje de programación interpretado, dialecto del estándar ECMAScript. Se utiliza principalmente en el desarrollo web para añadir interactividad a las páginas.

Creado en 10 días por Brendan Eich en 1995 mientras trabajaba en Netscape, ha evolucionado hasta convertirse en uno de los lenguajes más populares del mundo.

1995

Nace JavaScript (originalmente Mocha, luego LiveScript) creado por Brendan Eich en Netscape.

1997

Primer estándar ECMAScript (ES1). JavaScript se estandariza bajo el nombre ECMAScript.

2005

Aparece AJAX (Asynchronous JavaScript and XML), revolucionando las aplicaciones web.

2009

ES5 (ECMAScript 5) con nuevas características como JSON, strict mode y métodos de arrays.

2015

ES6 (ECMAScript 2015) - La mayor actualización: clases, módulos, arrow functions, let/const, etc.

2016-2022

Actualizaciones anuales (ES2016 a ES2022) con async/await, optional chaining, nullish coalescing y más.

Principales diferencias entre ES5 y ES6+:

  • Declaración de variables: let y const en lugar de solo var
  • Arrow functions: Sintaxis más corta para funciones
  • Clases: Sintaxis más clara para POO
  • Módulos: Import/export para organizar código
  • Template literals: Interpolación de strings con `${variable}`
  • Desestructuración: Extraer valores de objetos/arrays fácilmente

Enlazar JavaScript con HTML

Método Sintaxis Ventajas Desventajas Uso recomendado
Inline (en línea) <button onclick="miFunc()"> Rápido para pruebas Mezcla HTML/JS, difícil mantenimiento Evitar, solo para pruebas rápidas
Interno (script) <script> código JS </script> Útil para código específico de una página No reutilizable, mezcla estructura/comportamiento Pequeños scripts o configuraciones
Externo (archivo .js) <script src="script.js"></script> Mantenimiento fácil, reutilizable, caché Requiere HTTP request adicional Recomendado para la mayoría de casos
Módulos ES6 <script type="module" src="modulo.js"></script> Modularización, scope propio, import/export Soporte en navegadores modernos Proyectos modernos con múltiples archivos

Mejores prácticas:

  • Colocar scripts antes de cerrar </body> para no bloquear renderizado
  • Usar defer o async cuando sea necesario
  • Para módulos, usar type="module"
  • Organizar código en archivos por funcionalidad

Ejemplo recomendado:

<!-- Al final del body -->
<script src="js/main.js" defer></script>

Variables y Declaración

Tipos de variables

  • var - Alcance de función (evitar en ES6+)
  • let - Alcance de bloque, mutable
  • const - Alcance de bloque, inmutable

Tipos de datos

  • String - Cadena de texto
  • Number - Números (enteros/decimales)
  • Boolean - true/false
  • null - Valor nulo intencional
  • undefined - Variable no asignada
  • Object - Estructuras complejas
  • Symbol - Valor único (ES6+)

Ejemplos de declaración

// Variables mutables
let nombre = "Juan";
let edad = 30;
let esEstudiante = true;

// Constantes
const PI = 3.1416;
const COLORES = ["rojo", "verde"];

// Alcance de bloque (no funciona fuera de {})
{
  let mensaje = "Hola";
  const DESPEDIDA = "Adiós";
}

// Hoisting (solo con var, evitar)
console.log(x); // undefined
var x = 5;

Reglas para nombres de variables:

  • Pueden contener letras, números, _ y $
  • No pueden comenzar con número
  • Diferencia entre mayúsculas y minúsculas
  • Usar camelCase para nombres compuestos
  • Usar nombres descriptivos
  • Constantes en MAYÚSCULAS con _

Operadores

Aritméticos

  • + - * / % **
  • ++ -- (incremento/decremento)
  • += -= *= /= (asignación compuesta)

Comparación

  • == != (igualdad sin tipo)
  • === !== (igualdad estricta)
  • > < >= <=

Lógicos

  • && (AND)
  • || (OR)
  • ! (NOT)
  • ?? (Nullish coalescing - ES2020)

Ternario

condición ? expr1 : expr2

let acceso = edad >= 18 ? "Permitido" : "Denegado";

Ejemplos de operadores:

// Aritméticos
let suma = 5 + 3; // 8
let resto = 10 % 3; // 1
let potencia = 2 ** 3; // 8

// Comparación
5 == "5"; // true (coerción de tipos)
5 === "5"; // false

// Lógicos
true && false; // false
true || false; // true
!true; // false

// Nullish coalescing
let valor = null ?? "default"; // "default"

Estructuras de Control y Bucles

Condicionales

// if-else
if (edad >= 18) {
  console.log("Mayor de edad");
} else if (edad >= 12) {
  console.log("Adolescente");
} else {
  console.log("Niño");
}

// switch
switch(diaSemana) {
  case 1:
    console.log("Lunes");
    break;
  case 2:
    console.log("Martes");
    break;
  default:
    console.log("Otro día");
}

Bucles

// for
for(let i = 0; i < 5; i++) {
  console.log(i);
}

// while
let j = 0;
while(j < 5) {
  console.log(j);
  j++;
}

// do-while
let k = 0;
do {
  console.log(k);
  k++;
} while(k < 5);

// for-of (arrays)
const frutas = ['manzana', 'banana'];
for(const fruta of frutas) {
  console.log(fruta);
}

// for-in (objetos)
const persona = {nombre: 'Juan', edad: 30};
for(const clave in persona) {
  console.log(clave, persona[clave]);
}

Funciones

Declaración de funciones

// Declaración tradicional
function saludar(nombre) {
  return `Hola ${nombre}`;
}

// Expresión de función
const sumar = function(a, b) {
  return a + b;
};

// Arrow function (ES6+)
const multiplicar = (a, b) => a * b;

// Arrow function con múltiples líneas
const operacion = (a, b) => {
  const suma = a + b;
  const producto = a * b;
  return suma + producto;
};

Características

  • Parámetros: Pueden tener valores por defecto
  • Arguments: Objeto con todos los argumentos
  • Rest parameters: Captura múltiples argumentos como array
  • Scope: Las funciones crean su propio ámbito
// Parámetros por defecto
function saludar(nombre = "Usuario") {
  return `Hola ${nombre}`;
}

// Rest parameters
function sumar(...numeros) {
  return numeros.reduce((a, b) => a + b, 0);
}

// Funciones como valores
const operaciones = {
  sumar: (a, b) => a + b,
  restar: (a, b) => a - b
};
operaciones.sumar(5, 3); // 8

Diferencias entre function y arrow function:

  • Sintaxis: Arrow functions son más concisas
  • this: Las arrow functions no tienen su propio this
  • arguments: Las arrow functions no tienen objeto arguments
  • Constructor: Las arrow functions no pueden ser usadas como constructores

Módulo Math

El objeto Math proporciona propiedades y métodos para constantes y funciones matemáticas. No es un constructor, todas sus propiedades y métodos son estáticos.

Propiedades (Constantes)

  • Math.PI - π (3.141592...)
  • Math.E - e (2.718281...)
  • Math.SQRT2 - √2 (1.414213...)
  • Math.LN2 - ln(2) (0.693147...)

Métodos comunes

  • Math.round(x) - Redondeo
  • Math.floor(x) - Redondeo hacia abajo
  • Math.ceil(x) - Redondeo hacia arriba
  • Math.random() - Número aleatorio [0,1)

Operaciones matemáticas

  • Math.pow(x, y) - x elevado a y
  • Math.sqrt(x) - Raíz cuadrada
  • Math.abs(x) - Valor absoluto
  • Math.max(...nums) - Máximo

Funciones trigonométricas

  • Math.sin(x) - Seno (radianes)
  • Math.cos(x) - Coseno
  • Math.tan(x) - Tangente
  • Math.log(x) - Logaritmo natural

Ejemplos prácticos:

// Número aleatorio entre min y max
function randomInRange(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

// Calcular hipotenusa
function hipotenusa(a, b) {
  return Math.sqrt(Math.pow(a, 2) + Math.pow(b, 2));
}

// Redondear a 2 decimales
function redondear(num) {
  return Math.round(num * 100) / 100;
}

Objetos y Clases

Objetos literales

// Creación de objeto
const persona = {
  nombre: "Juan",
  edad: 30,
  saludar: function() {
    console.log(`Hola, soy ${this.nombre}`);
  }
};

// Acceso a propiedades
persona.nombre; // "Juan"
persona["edad"]; // 30
persona.saludar(); // "Hola, soy Juan"

// Añadir/modificar propiedades
persona.profesion = "Desarrollador";
persona.edad = 31;

Clases (ES6+)

// Definición de clase
class Persona {
  constructor(nombre, edad) {
    this.nombre = nombre;
    this.edad = edad;
  }

  // Método
  saludar() {
    console.log(`Hola, soy ${this.nombre}`);
  }
}

// Creación de instancia
const juan = new Persona("Juan", 30);
juan.saludar(); // "Hola, soy Juan"

// Herencia
class Desarrollador extends Persona {
  constructor(nombre, edad, lenguaje) {
    super(nombre, edad);
    this.lenguaje = lenguaje;
  }

  programar() {
    console.log(`Programando en ${this.lenguaje}`);
  }
}

const dev = new Desarrollador("Ana", 25, "JavaScript");
dev.saludar(); // "Hola, soy Ana"
dev.programar(); // "Programando en JavaScript"

Características de las clases:

  • constructor: Método especial para inicializar objetos
  • Métodos: Funciones definidas dentro de la clase
  • Herencia: Extender clases con extends
  • super: Llamar al constructor/métodos de la clase padre
  • static: Métodos/propiedades de clase (no de instancia)
  • Getters/Setters: Para acceder/modificar propiedades
