Semana 15: Sistemas Inteligentes con Python

Introducción a Sistemas Inteligentes

Los sistemas inteligentes combinan frameworks web con tecnologías de inteligencia artificial para crear aplicaciones avanzadas.

Tecnologías clave

  • Flask/Django: Frameworks web para construir la interfaz
  • LLAMA/Mistral: Modelos de lenguaje avanzados
  • Scikit-learn/TensorFlow: Machine Learning
  • NLTK/Spacy: Procesamiento de lenguaje natural

Integración de IA con Flask

Ejemplo: API de análisis de sentimientos

from flask import Flask, request, jsonify
from transformers import pipeline

app = Flask(__name__)
sentiment_analysis = pipeline("sentiment-analysis")

@app.route('/analyze', methods=['POST'])
def analyze():
  text = request.json.get('text')
  result = sentiment_analysis(text)[0]
  return jsonify({
    'sentiment': result['label'],
    'confidence': result['score']
  })

if __name__ == '__main__':
  app.run()

Django + Modelos de Lenguaje

Configuración básica con LLAMA

# settings.py
INSTALLED_APPS = [
  ...
  'llama_index',
  'langchain'
]

# views.py
from langchain.llms import LlamaCpp

def generate_text(request):
  llm = LlamaCpp(
    model_path="models/llama-2-7b-chat.ggmlv3.q4_0.bin",
    temperature=0.75
  )
  prompt = request.POST.get('prompt')
  response = llm(prompt)
  return JsonResponse({'response': response})

Ejemplo: Sistema de recomendación

import numpy as np
from sklearn.neighbors import NearestNeighbors

def recommend_products(user_preferences):
  # Datos de productos (features)
  products = np.array([[5,1], [3,1], [4,2], [1,5]])
  
  # Entrenar modelo
  model = NearestNeighbors(n_neighbors=2)
  model.fit(products)
  
  # Obtener recomendaciones
  distances, indices = model.kneighbors([user_preferences])
  return indices[0]
