Semana 2: Fundamentos de HTML - Estructura, Etiquetas y DOM

HTML vs XHTML

HTML (HyperText Markup Language)

Es el lenguaje estándar para crear páginas web. HTML describe la estructura de una página web mediante el uso de elementos (etiquetas).

Características principales:

  • Lenguaje de marcado, no de programación
  • Basado en etiquetas (tags)
  • Permite cierta flexibilidad en la sintaxis
  • Evoluciona constantemente (HTML5 es la última versión)

XHTML (Extensible HyperText Markup Language)

Es una reformulación de HTML como aplicación XML. Combina la familiaridad de HTML con el rigor de XML.

Características principales:

  • Sintaxis más estricta que HTML
  • Debe estar bien formado (well-formed)
  • Etiquetas deben cerrarse correctamente
  • Atributos deben ir entre comillas
  • Mejor compatibilidad con otros lenguajes basados en XML

Comparación entre HTML y XHTML

Característica HTML XHTML
Tipo de documento SGML XML
Estricto en sintaxis No Sí
Cierre de etiquetas Opcional en algunos casos Obligatorio siempre
Minúsculas en etiquetas No requerido Obligatorio
Atributos sin valor Permitidos (checked, disabled) No permitidos (debe ser checked="checked")
DOCTYPE Menos estricto Más específico

Anatomía de un Elemento HTML

Estructura básica de una etiqueta HTML:

<nombre-etiqueta atributo="valor">Contenido</nombre-etiqueta>

Componentes principales:

  1. Etiqueta de apertura: Indica el inicio del elemento (<p>)
  2. Etiqueta de cierre: Indica el fin del elemento (</p>)
  3. Contenido: Texto u otros elementos dentro del elemento
  4. Atributos: Proporcionan información adicional sobre el elemento

Ejemplo completo:

<a href="https://ejemplo.com" target="_blank" class="enlace" id="principal">Visitar sitio</a>

Elementos vacíos: Algunos elementos no tienen contenido ni etiqueta de cierre:

  • <img>
  • <br>
  • <hr>
  • <input>
  • <meta>

Etiquetas HTML Esenciales

Estructura básica

  • <!DOCTYPE html> - Declara el tipo de documento
  • <html> - Elemento raíz
  • <head> - Metadatos del documento
  • <body> - Contenido visible

Etiquetas de texto

  • <h1> a <h6> - Encabezados
  • <p> - Párrafos
  • <strong>, <em> - Énfasis
  • <span> - Contenedor genérico en línea

Etiquetas de agrupación

  • <div> - Contenedor genérico en bloque
  • <ul>, <ol>, <li> - Listas
  • <nav> - Navegación
  • <header>, <footer>, <section>, <article> - Semántica HTML5

Etiquetas multimedia

  • <img> - Imágenes
  • <audio>, <video> - Multimedia
  • <iframe> - Contenido embebido

Etiquetas de formulario

  • <form> - Formulario
  • <input> - Campo de entrada
  • <textarea> - Área de texto
  • <select>, <option> - Lista desplegable
  • <button> - Botón

Entidades HTML

Las entidades HTML son códigos especiales que representan caracteres que no se pueden teclear directamente o que tienen significado especial en HTML.

Ejemplos comunes:

Carácter Entidad Descripción
< &lt; Menor que (less than)
> &gt; Mayor que (greater than)
& &amp; Ampersand
" &quot; Comillas dobles
' &apos; Comilla simple (HTML5)
© &copy; Símbolo de copyright
® &reg; Símbolo registrado
€ &euro; Símbolo del euro
&nbsp; Espacio sin separación

Uso de entidades numéricas:

También se pueden usar códigos numéricos (decimales o hexadecimales):

  • &#169; - © (decimal)
  • &#xA9; - © (hexadecimal)
  • &#128512; - 😀 (emoji)

DOM (Document Object Model)

El DOM es una representación en forma de árbol de los elementos de un documento HTML, donde cada nodo es un objeto que representa parte del documento.

Estructura del DOM

Imagen representativa de un árbol DOM:

[Árbol DOM: document → html → (head, body) → etc.]

Características principales:

  • Representación jerárquica en forma de árbol
  • Cada elemento HTML es un nodo
  • Permite manipulación dinámica con JavaScript
  • Interfaz estandarizada para acceder y modificar documentos

Ejemplo de estructura DOM:

document
├── html
│ ├── head
│ │ ├── title
│ │ └── meta
│ └── body
│ ├── h1
│ ├── p
│ └── div
│ ├── p
│ └── ul
│ ├── li
│ └── li
└── ...

Relación entre HTML y DOM:

El navegador analiza (parsea) el código HTML y construye el árbol DOM que luego usa para renderizar la página. Cualquier cambio en el DOM se refleja en lo que se muestra al usuario.
