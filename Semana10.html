Semana 10: Desarrollo Web Backend con Java Spring

Java Spring Framework

Spring es el framework de aplicaciones Java más popular para construir aplicaciones empresariales. Proporciona un modelo de programación completo para aplicaciones backend.

Principales módulos de Spring

  • Spring Core: Inversión de Control (IoC) y Inyección de Dependencias
  • Spring MVC: Para aplicaciones web
  • Spring Boot: Autoconfiguración para proyectos rápidos
  • Spring Security: Autenticación y autorización
  • Spring Data: Simplifica el acceso a datos

Ejemplo de Controlador Spring MVC

@RestController
@RequestMapping("/api")
public class ProductoController {

  @Autowired
  private ProductoService productoService;

  @GetMapping("/productos")
  public List<Producto> listarProductos() {
    return productoService.obtenerTodos();
  }
}

JSP / Jakarta EE con Spring

JavaServer Pages (JSP) es una tecnología para crear páginas web dinámicas. Spring MVC puede integrarse con JSP para la capa de vista.

Ventajas de usar JSP con Spring

  • Fácil integración con Java
  • Taglibs para reutilización de código
  • Expression Language (EL) para acceso a datos
  • JSTL para lógica de presentación

Ejemplo de JSP con Spring MVC

<!-- Controlador -->
@Controller
public class HomeController {
  @GetMapping("/")
  public String home(Model model) {
    model.addAttribute("mensaje", "Bienvenido");
    return "home";
  }
}

<!-- Vista home.jsp -->
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
<h1>${mensaje}</h1>

Spring Data, Hibernate y JPA

Comparación de tecnologías

Tecnología Descripción Ventajas
JPA Especificación para mapeo objeto-relacional Estándar, independiente del proveedor
Hibernate Implementación más popular de JPA Rico conjunto de características, maduro
Spring Data JPA Abstracción sobre JPA/Hibernate Reduce código boilerplate, repositorios

  @Id

  private Long id;

  @Column(nullable = false)
  private String nombre;

  // Getters y Setters
}

Ejemplo de Repositorio Spring Data

public interface ProductoRepository extends JpaRepository<Producto, Long> {
  List<Producto> findByNombreContaining(String nombre);
  @Query("SELECT p FROM Producto p WHERE p.precio > :precio")
  List<Producto> findProductosConPrecioMayorA(@Param("precio") BigDecimal precio);
}

Flujo típico Spring MVC + JPA

  1. Cliente realiza petición HTTP
  2. Spring MVC recibe la petición y la enruta al controlador adecuado
  3. El controlador llama al servicio correspondiente
  4. El servicio utiliza el repositorio Spring Data JPA
  5. Spring Data JPA usa Hibernate para interactuar con la base de datos
  6. Los resultados viajan de vuelta al cliente

Ejemplo completo Service + Controller

@Service
public class ProductoService {
  @Autowired
  private ProductoRepository repository;

  public List<Producto> buscarPorNombre(String nombre) {
    return repository.findByNombreContaining(nombre);
  }
}

@RestController
@RequestMapping("/api/productos")
public class ProductoController {
  @Autowired
  private ProductoService service;

  @GetMapping
  public ResponseEntity<List<Producto>> buscar(@RequestParam String nombre) {
    return ResponseEntity.ok(service.buscarPorNombre(nombre));
  }
}
